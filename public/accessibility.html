Accessibility Statement

Last updated: September 2026

Commitment to Accessibility

Glycolysis Interactive is committed to ensuring digital accessibility for all users, including people with disabilities. We target the Web Content Accessibility Guidelines (WCAG) 2.1 Level AA. This site has not yet undergone a formal third-party accessibility audit, so conformance cannot currently be claimed; the measures below describe the accessibility architecture as implemented.

Keyboard Navigation

All interactive elements on this site are fully keyboard accessible:

  • Molecule selector — A radio group with roving tabindex: Tab moves focus into the grid, Arrow keys (or j/k) move between molecules, Enter or Space selects, and Home and End jump to first/last item.
  • Viewer controls — Hydrogen toggle, auto-rotation, and reset are all keyboard-operable buttons.
  • Interactive Story — Scene navigation supports keyboard shortcuts (Arrow keys or Space for scenes, P to pause or resume the story, N for narration, R for rotation, H for hydrogens, S to stop auto-advance, Escape to stop narration). Shortcuts are disabled while a text field has focus or when combined with modifier keys.
  • Skip links — A skip-to-content link is the first focusable element on every page and becomes visible when focused.

Screen Reader Support

  • Molecule changes are announced via aria-live regions.
  • The 3D viewer includes a descriptive aria-label and hidden molecule description that updates with each selection.
  • All buttons and controls have explicit accessible names.
  • The molecule grid uses role="radiogroup" with aria-checked state management.

Reduced Motion

The site respects the prefers-reduced-motion system preference. When enabled:

  • CSS animations and transitions are suppressed.
  • 3D molecule auto-rotation is disabled by default.
  • The interactive story reduces particle effects and transition durations.

Color and Contrast

The site uses a high-contrast dark theme. Primary text and interactive controls maintain a contrast ratio of at least 4.5:1 against their backgrounds. Decorative legend text has been held to the same standard. Interactive elements use visible focus indicators with a 2px accent-colored outline.

Touch Targets

Primary interactive elements provide a touch target of at least 44×44 pixels. A small number of auxiliary overlay controls in the interactive story are smaller at desktop sizes and remain fully keyboard-operable.

Known Limitations

  • The 3D molecular viewer relies on WebGL, which may not be available in all assistive technology contexts. Molecular information (name, formula) is provided as text alongside the viewer.
  • Speech synthesis narration in the interactive story varies by browser and operating system.

Feedback

If you encounter any accessibility barriers on this site, please open an issue on the project's GitHub repository. We welcome feedback and will work to address any issues promptly.
