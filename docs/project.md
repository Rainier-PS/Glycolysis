# Glycolysis — Project Documentation

## 1. Project Overview

An interactive educational website for exploring glycolysis through two complementary experiences:

1. **Landing Page + 3D Viewer** (`index.html`) — Hero section with scroll-to-viewer flow, interactive 3D molecular viewer with 15 molecule selector grid, and premium footer
2. **Interactive Story** (`story/index.html`) — A cinematic, narrated documentary that walks through all ten enzyme-catalyzed reactions of glycolysis with 3D molecular visualization

Both use 3Dmol.js for real-time 3D molecular rendering of SDF-based structures and share canonical molecular assets.

## 3. Architecture

### Landing Page
- `index.html` — HTML structure only; all styling lives in `styles/landing.css` and all logic in external `src/viewer.js` + `src/init.js`. The page contains an inline decorative hero SVG (presentation markup, not CSS/JS logic)
- References `styles/landing.css` for all styling
- References `vendor/3dmol/3Dmol-min.js` (synchronous, required before init)
- References `src/viewer.js` (3Dmol wrapper + molecule catalogue)
- References `src/init.js` (DOM wiring, grid builder, keyboard nav)
- Dark cinematic palette with CSS custom properties (`--bg`, `--text`, `--muted`, `--accent`, `--line`, `--radius`)
- 5×3 molecule selector grid on the left, 3D viewer on the right (1fr 1fr split)
- Atom color legend with hover tooltips inside the viewer
- Viewer controls: AUTO (rotation), H (hydrogens), RESET
- Default selection: glucose loads on page load
- Responsive breakpoints: 1100px, 1023px, 768px, 480px, 430px

### Legal Pages
- `privacy.html`, `terms.html`, `accessibility.html`
- Shared `styles/legal.css` (DRY — single source for all legal page styles)
- Each has: skip-to-content link, back-to-home link, header, main content, mini footer with cross-links
- Wider content area (960px) with larger body text (17px) for readability

### Story Page
- Separate HTML document with external `story.css` and `story.js`
- IIFE-scoped JavaScript
- 27 scenes with narration, captions, and molecular transitions
- Web Speech API for narration

### Shared Assets
- 3Dmol.js: `vendor/3dmol/3Dmol-min.js` (single canonical copy)
- Molecules: `molecules/` (15 SDF files, one per molecule)

## 5. Scientific Model

Ten reactions of glycolysis with correct accounting:
- Investment: 2 ATP consumed
- Payoff: 4 ATP produced, 2 NADH produced
- Net: +2 ATP, +2 NADH, 2 pyruvate

Overall: Glucose + 2 NAD+ + 2 ADP + 2 Pi → 2 Pyruvate + 2 NADH + 2 ATP + 2 H+ + 2 H2O

## 6. Molecular Assets

15 canonical SDF files in `molecules/`. Each molecule has a subdirectory containing one `.sdf` file. SDF geometry is authoritative; coordinates are not regenerated by the UI.

Molecule data is defined in two places:
- `src/viewer.js` — `MOLECULES` array (used by landing page viewer)
- `story/story.js` — `MOL` object (used by story page viewer)

Both reference the same SDF files. When adding a molecule, add entries to both.

## 7. 3Dmol.js

Single canonical copy at `vendor/3dmol/3Dmol-min.js`. Referenced by both landing page and story page. Do not duplicate.

## 9. Accessibility

### All Pages
- Skip link as the first focusable element; visible on focus (`:focus`/`:focus-visible`)
- Focus-visible outlines on all interactive elements (2px accent-colored)

### Landing Page
- Skip link targets `#viewerSection`
- `role="radiogroup"` on the molecule grid with `role="radio"` buttons managed via `aria-checked` and roving tabindex
- `aria-pressed` on toggle buttons (AUTO, H)
- `aria-live="polite"` on the viewer info bar (`#viewerInfo`) for molecule change announcements
- `aria-label` on all interactive controls
- `aria-hidden="true"` on decorative elements (hero cell, hero molecule, legend dots)
- Touch targets minimum 44×44px (`.vc-btn`)
- Reduced motion: `prefers-reduced-motion: reduce` suppresses transitions and hover transforms

### Legal Pages
- Skip-to-content link on all three pages
- `id="mainContent"` on `<main>` for skip link target
- Touch targets minimum 44px (`.back-link`, `.footer-mini a`)

### Story Page
- `#srLive` (aria-live="polite") for narrative announcements
- `#srMolDesc` (role="img") for dynamic molecule description
- `#viewport` with `aria-describedby="srMolDesc"`
- `#countdownText` with `role="timer"` (not aria-live, to avoid screen-reader spam)
- Keyboard shortcuts: N, R, H, S, Escape, arrows, space
- Touch targets minimum 44px (`.sctrl`, `.nar-btn`); small auxiliary toolbar buttons (`.vtb`) are smaller but keyboard-operable

## 10. Performance

- SDF caching with deduplication (prevents re-fetching on re-selection)
- Viewer initializes lazily (3Dmol only needed on first molecule click)
- `overflow-x: hidden` on body prevents horizontal scroll
- `touch-action: none` on 3D canvas prevents scroll conflicts
- No unnecessary frameworks or dependencies
- `visibilitychange` stops narration/rotation when hidden (story page)

## 11. File Organization (DRY)

- **`styles/legal.css`** — Single shared stylesheet for all 3 legal pages (no duplicated CSS)
- **`src/viewer.js`** — Single source of truth for molecule metadata on the landing page
- **CSS custom properties** — Shared `:root` variables per stylesheet
- **No inline `<style>` or `<script>` blocks** — All styling in external `.css` files, all logic in external `.js` files

## 12. Development Workflow

### Local Testing
Serve project root directory with any static HTTP server. No build step required.

### Adding a Molecule
1. Place SDF in `molecules/<key>/<key>.sdf`
2. Add entry to `MOLECULES` in `src/viewer.js` (landing page)
3. Add entry to `MOL` in `story/story.js` (story page)
4. Both pages will pick up the new molecule automatically

### Modifying Story Scenes
Edit `scenes` array in `story/story.js`. Each scene has: id, phase, molecule, camera, captions, enzyme, reaction, perReaction, timesPerGlucose, accounting, atmosphere, preloads, autoAdvanceDelay.

## 13. Known Limitations

1. 3Dmol.js loaded from relative path; both pages break if vendor file is missing
2. Speech synthesis varies by browser/OS
3. Linear documentary flow in story (no click-to-jump)
4. Production domain not yet configured (uses placeholder URLs)
5. Google Search Console verification not yet completed
6. `src/main.js` and `styles/main.css` reference DOM (e.g. `#reactionScenes`, `#pathwayNav`) that no page provides; they are retained as extension scaffolding and must not be loaded as-is

## 14. What NOT to Change Casually

- SDF molecular geometry
- PubChem CIDs
- Reaction sequence or accounting
- Overall glycolysis equation
- 3Dmol version
- Scene order or timing in story
- Narration text
- Accessibility architecture (skip links, aria attributes, focus management, roving tabindex)
- Relative path structure
- The separation between landing page and story page
- `src/viewer.js` molecule data (MOLECULES array) — shared with init.js
- `styles/landing.css` and `styles/legal.css` — external stylesheets, no inline fallback
